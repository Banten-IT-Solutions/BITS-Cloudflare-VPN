## ✨ Features

| Feature | Description |
|---------|-------------|
| **Multi-Protocol Relay** | Supports VLESS, VMess, and Trojan over WebSocket. |
| **Four Frontend Pages** | `/`, `/build`, `/country`, `/convert`. |
| **Provider Build** | Build config from proxy list with search, filter, and ping check. |
| **Country Build** | Build config by country path like `/ID` or `/ID,SG`. |
| **URI ↔ Clash Converter** | Convert VLESS / VMess / Trojan URI to Clash YAML and back. |
| **Proxy List API** | Paginated proxy list with country, port, and query filters. |
| **Country KV Source** | Country buckets loaded from `KV.json` for relay routing. |
| **Latency Probe** | `/api/check` validates allowed proxy target with rate limit. |
| **Cloudflare Native** | Runs on Workers, Assets, custom domain, and observability. |
| **Automated Data Sync** | `proxy.txt`, `raw.txt`, and `KV.json` generated by helper scripts. |

## 🛠️ Tech Stack

| Layer | Technology |

## 🚀 Quick Start

### Prerequisites

- Node.js 20+ or Bun 1+
- Cloudflare account
- Wrangler CLI

### Steps

```bash
git clone https://github.com/Banten-IT-Solutions/BITS-Cloudflare-VPN.git
cd BITS-Cloudflare-VPN
bun install
```

Run local dev:

```bash
bun run dev
```

Deploy:

```bash
bun run deploy
```

## ⚙️ Configuration

### `wrangler.toml`

```toml
name = "vpn"
main = "src/index.ts"
compatibility_date = "2024-09-23"
compatibility_flags = ["nodejs_compat_v2"]

[vars]
PRX_BANK_URL = "https://raw.githubusercontent.com/Banten-IT-Solutions/BITS-Cloudflare-VPN/main/proxy.txt"

[assets]
directory = "./assets"
binding = "ASSETS"

[[routes]]
pattern = "your-domain.com"
custom_domain = true
```

### Optional env

| Variable | Description |
|----------|-------------|
| `PRX_BANK_URL` | Remote raw proxy source for `/api/proxies` and `/api/sub`. |
| `KV_PRX_URL` | Optional country bucket source, defaults to `KV.json`. |

## 📡 API Endpoints

All endpoints under `/api`.

### 1. `GET /api/sub`

Generate subscription output.

**Query params**

| Param | Description | Default |
|-------|-------------|---------|
| `vpn` | Protocol filter: `vless`, `vmess`, `trojan` | `vless` |
| `cc` | Country filter, comma-separated | all |
| `port` | Port filter: `443`, `80` | `443,80` |
| `limit` | Max output count | `10` |
| `format` | `raw`, `v2ray`, `json` | `raw` |
| `domain` | Override host / SNI domain | request host |

**Example**

```bash
curl "https://domain.com/api/sub?vpn=vless&cc=ID&limit=5&format=raw"
```

### 2. `GET /api/proxies`

Paginated proxy list.

**Query params**

| Param | Description |
|-------|-------------|
| `q` | Search by IP, country, or org |
| `cc` | Country filter |
| `port` | Port filter |
| `page` | Page number |
| `limit` | Items per page, max `100` |

### 3. `GET /api/countries`

Country list with proxy count from KV source.

### 4. `GET /api/myip`

Return client IP and Cloudflare colo data.

### 5. `GET /api/check`

Latency probe for allowed proxy target.

**Query params**

| Param | Description |
|-------|-------------|
| `target` | Target in `IP:PORT` format |

> Rate limit active. Target must exist in allowlist proxy data.

## 🔐 Security Notes

- `/api/check` only accepts allowlist target.
- Rate limit active on probe endpoint.
- HTTP redirects to HTTPS for non-local requests.
- WebSocket relay uses country bucket or direct proxy target path.
- CORS is wide for Worker deployment flow.
